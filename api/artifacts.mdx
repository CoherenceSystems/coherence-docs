Artifact records are the auditable output of a Coherence Atlas review. Each artifact captures a structured snapshot of what was observed — persistence summaries, drift events, detected transitions, and explicit claim boundaries — so that findings remain traceable and reviewable long after the analysis window closes. You create artifacts during or after a review session and export them for downstream reporting or compliance workflows.

<Note>
  All requests require a Bearer token in the `Authorization` header. Base URL: `https://api.coherencesystems.net/v1`
</Note>

---

## POST /artifacts

Create a new artifact record linked to a review session and signal set. You can populate findings at creation time or leave them empty and update the record as the review progresses.

### Request body

<ParamField body="review_session_id" type="string" required>
  The identifier of the review session this artifact belongs to (e.g., `rev_01xyz`).
</ParamField>

<ParamField body="signal_set_id" type="string" required>
  The identifier of the signal set that was analyzed (e.g., `sig_01abc`).
</ParamField>

<ParamField body="findings" type="object">
  Structured analysis findings. You can populate this at creation or update it later with `PATCH /artifacts/{id}`.

  <Expandable title="Findings fields">
    <ParamField body="findings.persistence_summary" type="string">
      Plain-language summary of persistence behavior observed across the review window.
    </ParamField>
    <ParamField body="findings.drift_events" type="integer">
      Number of drift events detected during the review window.
    </ParamField>
    <ParamField body="findings.transition_detected" type="boolean">
      Whether a transition was detected during the review window.
    </ParamField>
    <ParamField body="findings.transition_window" type="object">
      The time offsets (in minutes from window start) bounding the detected transition.
      <Expandable title="Transition window fields">
        <ParamField body="findings.transition_window.start" type="number">
          Start offset in minutes from the beginning of the review window.
        </ParamField>
        <ParamField body="findings.transition_window.end" type="number">
          End offset in minutes from the beginning of the review window.
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="claim_boundaries" type="array of strings">
  Explicit statements scoping the limits of the analysis — what was not assessed, what data was unavailable, or what conditions constrain the findings.
</ParamField>

### Example request

```bash
curl -X POST https://api.coherencesystems.net/v1/artifacts \
  -H "Authorization: Bearer $ATLAS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "review_session_id": "rev_01xyz",
    "signal_set_id": "sig_01abc",
    "findings": {
      "persistence_summary": "Structure held across fine and mid scales throughout the review window.",
      "drift_events": 2,
      "transition_detected": true,
      "transition_window": { "start": 45, "end": 62 }
    },
    "claim_boundaries": [
      "Analysis limited to registered progression 0–100.",
      "Broad-scale structure was not available for the final 20% of the window."
    ]
  }'
```

### Example response

```json
{
  "id": "art_01abc",
  "review_session_id": "rev_01xyz",
  "signal_set_id": "sig_01abc",
  "findings": {
    "persistence_summary": "Structure held across fine and mid scales throughout the review window.",
    "drift_events": 2,
    "transition_detected": true,
    "transition_window": { "start": 45, "end": 62 }
  },
  "claim_boundaries": [
    "Analysis limited to registered progression 0–100.",
    "Broad-scale structure was not available for the final 20% of the window."
  ],
  "created_at": "2025-01-15T12:00:00Z",
  "updated_at": "2025-01-15T12:00:00Z"
}
```

### Error codes

| Code | Meaning |
|---|---|
| `400` | Missing required field or malformed findings object |
| `404` | `review_session_id` or `signal_set_id` not found |
| `409` | An artifact already exists for this review session and signal set combination |

## GET /artifacts

List artifact records for your account. Use filter parameters to narrow results by review session, signal set, or creation date range.

### Query parameters

<ParamField query="review_session_id" type="string">
  Filter to artifacts belonging to a specific review session.
</ParamField>

<ParamField query="signal_set_id" type="string">
  Filter to artifacts derived from a specific signal set.
</ParamField>

<ParamField query="date_from" type="string (ISO 8601)">
  Return artifacts created on or after this date (e.g., `2025-01-01T00:00:00Z`).
</ParamField>

<ParamField query="date_to" type="string (ISO 8601)">
  Return artifacts created on or before this date.
</ParamField>

<ParamField query="transition_detected" type="boolean">
  Filter to artifacts where a transition was or was not detected.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum results per page. Default: `20`. Maximum: `100`.
</ParamField>

<ParamField query="offset" type="integer">
  Pagination offset. Default: `0`.
</ParamField>

### Example request

```bash
curl "https://api.coherencesystems.net/v1/artifacts?signal_set_id=sig_01abc&date_from=2025-01-01T00:00:00Z&limit=20" \
  -H "Authorization: Bearer $ATLAS_TOKEN"
```

### Example response

```json
{
  "data": [
    {
      "id": "art_01abc",
      "review_session_id": "rev_01xyz",
      "signal_set_id": "sig_01abc",
      "findings": {
        "persistence_summary": "Structure held across fine and mid scales throughout the review window.",
        "drift_events": 2,
        "transition_detected": true,
        "transition_window": { "start": 45, "end": 62 }
      },
      "claim_boundaries": [
        "Analysis limited to registered progression 0–100.",
        "Broad-scale structure was not available for the final 20% of the window."
      ],
      "created_at": "2025-01-15T12:00:00Z",
      "updated_at": "2025-01-15T14:30:00Z"
    }
  ],
  "total": 1,
  "limit": 20,
  "offset": 0
}
```

### Error codes

| Code | Meaning |
|---|---|
| `400` | Invalid filter parameter value or malformed date string |

## PATCH /artifacts/{id}

Update the metadata or findings of an existing artifact record. Use this endpoint to add findings incrementally as a review progresses, revise claim boundaries, or append notes. You cannot change the `review_session_id` or `signal_set_id` after creation.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the artifact to update.
</ParamField>

### Request body

<ParamField body="findings" type="object">
  Updated findings object. Provided fields are merged into the existing findings — fields not included in the request are preserved.

  <Expandable title="Updatable findings fields">
    <ParamField body="findings.persistence_summary" type="string">
      Revised persistence summary.
    </ParamField>
    <ParamField body="findings.drift_events" type="integer">
      Updated count of drift events.
    </ParamField>
    <ParamField body="findings.transition_detected" type="boolean">
      Revised transition detection flag.
    </ParamField>
    <ParamField body="findings.transition_window" type="object">
      Updated transition window offsets.
      <Expandable title="Transition window fields">
        <ParamField body="findings.transition_window.start" type="number">
          Start offset in minutes.
        </ParamField>
        <ParamField body="findings.transition_window.end" type="number">
          End offset in minutes.
        </ParamField>
      </Expandable>
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="claim_boundaries" type="array of strings">
  Replacement claim boundaries list. This overwrites the existing list entirely — include all boundaries you want to retain.
</ParamField>

### Example request

```bash
curl -X PATCH https://api.coherencesystems.net/v1/artifacts/art_01abc \
  -H "Authorization: Bearer $ATLAS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "findings": {
      "persistence_summary": "Structure held across fine and mid scales throughout the review window. Post-transition recovery was confirmed at both scales.",
      "drift_events": 2
    },
    "claim_boundaries": [
      "Analysis limited to registered progression 0–100.",
      "Broad-scale structure was not available for the final 20% of the window.",
      "Post-transition recovery assessment is preliminary pending additional observation data."
    ]
  }'
```

### Example response

```json
{
  "id": "art_01abc",
  "review_session_id": "rev_01xyz",
  "signal_set_id": "sig_01abc",
  "findings": {
    "persistence_summary": "Structure held across fine and mid scales throughout the review window. Post-transition recovery was confirmed at both scales.",
    "drift_events": 2,
    "transition_detected": true,
    "transition_window": { "start": 45, "end": 62 }
  },
  "claim_boundaries": [
    "Analysis limited to registered progression 0–100.",
    "Broad-scale structure was not available for the final 20% of the window.",
    "Post-transition recovery assessment is preliminary pending additional observation data."
  ],
  "created_at": "2025-01-15T12:00:00Z",
  "updated_at": "2025-01-15T16:00:00Z"
}
```

### Error codes

| Code | Meaning |
|---|---|
| `400` | Attempt to modify immutable fields (`review_session_id`, `signal_set_id`) |
| `404` | Artifact not found |
| `422` | Malformed findings object |

## DELETE /artifacts/{id}

Remove an artifact record permanently. Deletion cannot be undone. The associated review session and signal set are not affected.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the artifact to remove.
</ParamField>

### Example request

```bash
curl -X DELETE https://api.coherencesystems.net/v1/artifacts/art_01abc \
  -H "Authorization: Bearer $ATLAS_TOKEN"
```

### Example response

```json
{
  "id": "art_01abc",
  "deleted": true,
  "deleted_at": "2025-01-16T09:00:00Z"
}
```

### Error codes

| Code | Meaning |
|---|---|
| `404` | Artifact not found |
| `409` | Artifact is locked by an in-progress export job |

## GET /artifacts/{id}/export

Export an artifact record as a structured JSON document or a formatted PDF report. Exports are generated asynchronously for PDF format — the response includes a download URL valid for 24 hours.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the artifact to export.
</ParamField>

### Query parameters

<ParamField query="format" type="string" required>
  Export format. Accepted values: `json`, `pdf`.
</ParamField>

<ParamField query="include_trace" type="boolean">
  If `true`, embed the full drift and persistence trace data in the export. Applies to `json` format only. Default: `false`.
</ParamField>

### Example request

```bash
curl "https://api.coherencesystems.net/v1/artifacts/art_01abc/export?format=pdf" \
  -H "Authorization: Bearer $ATLAS_TOKEN"
```

### Example response

<Tabs>
  <Tab title="JSON format">
    ```json
    {
      "id": "art_01abc",
      "format": "json",
      "export": {
        "review_session_id": "rev_01xyz",
        "signal_set_id": "sig_01abc",
        "findings": {
          "persistence_summary": "Structure held across fine and mid scales throughout the review window.",
          "drift_events": 2,
          "transition_detected": true,
          "transition_window": { "start": 45, "end": 62 }
        },
        "claim_boundaries": [
          "Analysis limited to registered progression 0–100.",
          "Broad-scale structure was not available for the final 20% of the window."
        ],
        "exported_at": "2025-01-16T09:05:00Z"
      }
    }
    ```
  </Tab>
  <Tab title="PDF format">
    ```json
    {
      "id": "art_01abc",
      "format": "pdf",
      "status": "ready",
      "download_url": "https://exports.coherencesystems.net/artifacts/art_01abc/report.pdf?token=eyJ...",

      "generated_at": "2025-01-16T09:05:00Z"
    }
    ```
  </Tab>
</Tabs>

### Error codes

| Code | Meaning |
|---|---|
| `400` | Invalid or missing `format` parameter |
| `404` | Artifact not found |
| `422` | Artifact has no findings populated — populate findings before exporting |
