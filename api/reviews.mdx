Structured review sessions are the organizing unit of analysis in Coherence Atlas. A review session ties a signal set to an explicit review question, a defined time range, and a set of known conditions — keeping that context visible throughout interpretation. When a session concludes, you retrieve a consolidated summary of persistence, drift, and transition findings across all registered views.

<Note>
  All requests require a Bearer token in the `Authorization` header. Base URL: `https://api.coherencesystems.net/v1`
</Note>

---

## POST /reviews

Create a new review session. Provide the signal set to analyze, the review question guiding interpretation, the time range under examination, and any known conditions that should be held alongside the analysis.

### Request body

<ParamField body="signal_set_id" type="string" required>
  The identifier of the signal set to analyze in this session (e.g., `sig_01abc`).
</ParamField>

<ParamField body="context" type="object" required>
  The review context that stays visible throughout the session. Context is never inferred — you define it explicitly before analysis begins.

  <Expandable title="Context fields">
    <ParamField body="context.review_question" type="string" required>
      The specific question this review session is designed to answer. State it precisely — this question anchors all findings and claim boundaries in the resulting artifact.
    </ParamField>
    <ParamField body="context.time_range" type="object" required>
      The time window to analyze.
      <Expandable title="Time range fields">
        <ParamField body="context.time_range.start" type="string (ISO 8601)" required>
          Start of the analysis window (e.g., `2025-01-14T00:00:00Z`).
        </ParamField>
        <ParamField body="context.time_range.end" type="string (ISO 8601)" required>
          End of the analysis window.
        </ParamField>
      </Expandable>
    </ParamField>
    <ParamField body="context.known_conditions" type="array of strings">
      Conditions known to be active during the review window — maintenance events, environmental factors, operational state changes. These are registered as context, not as analysis inputs.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="name" type="string">
  Optional human-readable name for the session (e.g., `post-maintenance-thermal-check-jan14`). If omitted, a name is generated from the signal set name and timestamp.
</ParamField>

<ParamField body="tags" type="array of strings">
  Optional labels for filtering and organizing sessions.
</ParamField>

### Example request

```bash
curl -X POST https://api.coherencesystems.net/v1/reviews \
  -H "Authorization: Bearer $ATLAS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "signal_set_id": "sig_01abc",
    "name": "post-maintenance-thermal-check-jan14",
    "context": {
      "review_question": "Does the thermal array show persistent structure after the scheduled maintenance window?",
      "time_range": {
        "start": "2025-01-14T00:00:00Z",
        "end": "2025-01-15T00:00:00Z"
      },
      "known_conditions": [
        "Maintenance window 2025-01-14T04:00Z to 2025-01-14T06:00Z",
        "Ambient temperature elevated by 3°C relative to baseline"
      ]
    },
    "tags": ["thermal", "post-maintenance"]
  }'
```

### Example response

```json
{
  "id": "rev_01xyz",
  "name": "post-maintenance-thermal-check-jan14",
  "signal_set_id": "sig_01abc",
  "status": "active",
  "context": {
    "review_question": "Does the thermal array show persistent structure after the scheduled maintenance window?",
    "time_range": {
      "start": "2025-01-14T00:00:00Z",
      "end": "2025-01-15T00:00:00Z"
    },
    "known_conditions": [
      "Maintenance window 2025-01-14T04:00Z to 2025-01-14T06:00Z",
      "Ambient temperature elevated by 3°C relative to baseline"
    ]
  },
  "tags": ["thermal", "post-maintenance"],
  "artifact_count": 0,
  "created_at": "2025-01-15T12:00:00Z",
  "updated_at": "2025-01-15T12:00:00Z"
}
```

### Error codes

| Code | Meaning |
|---|---|
| `400` | Missing required field or malformed context object |
| `404` | `signal_set_id` not found or not ready for analysis |
| `422` | `time_range` falls outside the available observation data for the signal set |

## GET /reviews

List review sessions for your account. Filter by signal set, status, or tag to narrow results.

### Query parameters

<ParamField query="signal_set_id" type="string">
  Filter to sessions analyzing a specific signal set.
</ParamField>

<ParamField query="status" type="string">
  Filter by session status. Accepted values: `active`, `completed`, `cancelled`.
</ParamField>

<ParamField query="tag" type="string">
  Filter to sessions that include this tag (exact match).
</ParamField>

<ParamField query="date_from" type="string (ISO 8601)">
  Return sessions created on or after this date.
</ParamField>

<ParamField query="date_to" type="string (ISO 8601)">
  Return sessions created on or before this date.
</ParamField>

<ParamField query="limit" type="integer">
  Maximum results per page. Default: `20`. Maximum: `100`.
</ParamField>

<ParamField query="offset" type="integer">
  Pagination offset. Default: `0`.
</ParamField>

### Example request

```bash
curl "https://api.coherencesystems.net/v1/reviews?status=active&signal_set_id=sig_01abc" \
  -H "Authorization: Bearer $ATLAS_TOKEN"
```

### Example response

```json
{
  "data": [
    {
      "id": "rev_01xyz",
      "name": "post-maintenance-thermal-check-jan14",
      "signal_set_id": "sig_01abc",
      "status": "active",
      "context": {
        "review_question": "Does the thermal array show persistent structure after the scheduled maintenance window?",
        "time_range": {
          "start": "2025-01-14T00:00:00Z",
          "end": "2025-01-15T00:00:00Z"
        },
        "known_conditions": [
          "Maintenance window 2025-01-14T04:00Z to 2025-01-14T06:00Z",
          "Ambient temperature elevated by 3°C relative to baseline"
        ]
      },
      "tags": ["thermal", "post-maintenance"],
      "artifact_count": 1,
      "created_at": "2025-01-15T12:00:00Z",
      "updated_at": "2025-01-15T14:30:00Z"
    }
  ],
  "total": 1,
  "limit": 20,
  "offset": 0
}
```

### Error codes

| Code | Meaning |
|---|---|
| `400` | Invalid filter parameter or malformed date string |

## PATCH /reviews/{id}

Update the context or status of a review session. Use this endpoint to refine the review question, add known conditions discovered mid-review, update tags, or mark the session as completed.

<Warning>
  Updating `context.review_question` after artifacts have been created does not retroactively update those artifact records. Add a `claim_boundary` to affected artifacts to note the question was revised.
</Warning>

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the review session to update.
</ParamField>

### Request body

<ParamField body="name" type="string">
  Updated session name.
</ParamField>

<ParamField body="status" type="string">
  Update the session lifecycle status. Accepted values: `active`, `completed`. Use `DELETE /reviews/{id}` to cancel.
</ParamField>

<ParamField body="context" type="object">
  Updated context fields. Provided sub-fields are merged — fields not included are preserved.

  <Expandable title="Updatable context fields">
    <ParamField body="context.review_question" type="string">
      Revised review question.
    </ParamField>
    <ParamField body="context.known_conditions" type="array of strings">
      Replacement known conditions list. This overwrites the existing list — include all conditions you want to retain.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="tags" type="array of strings">
  Replacement tag list. Overwrites existing tags entirely.
</ParamField>

### Example request

```bash
curl -X PATCH https://api.coherencesystems.net/v1/reviews/rev_01xyz \
  -H "Authorization: Bearer $ATLAS_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "completed",
    "context": {
      "known_conditions": [
        "Maintenance window 2025-01-14T04:00Z to 2025-01-14T06:00Z",
        "Ambient temperature elevated by 3°C relative to baseline",
        "Secondary coolant pump operating at reduced capacity from 2025-01-14T08:00Z"
      ]
    },
    "tags": ["thermal", "post-maintenance", "completed"]
  }'
```

### Example response

```json
{
  "id": "rev_01xyz",
  "name": "post-maintenance-thermal-check-jan14",
  "signal_set_id": "sig_01abc",
  "status": "completed",
  "context": {
    "review_question": "Does the thermal array show persistent structure after the scheduled maintenance window?",
    "time_range": {
      "start": "2025-01-14T00:00:00Z",
      "end": "2025-01-15T00:00:00Z"
    },
    "known_conditions": [
      "Maintenance window 2025-01-14T04:00Z to 2025-01-14T06:00Z",
      "Ambient temperature elevated by 3°C relative to baseline",
      "Secondary coolant pump operating at reduced capacity from 2025-01-14T08:00Z"
    ]
  },
  "tags": ["thermal", "post-maintenance", "completed"],
  "artifact_count": 1,
  "created_at": "2025-01-15T12:00:00Z",
  "updated_at": "2025-01-15T17:00:00Z"
}
```

### Error codes

| Code | Meaning |
|---|---|
| `400` | Invalid `status` value or attempt to reopen a `cancelled` session |
| `404` | Review session not found |

## DELETE /reviews/{id}

Cancel and remove a review session. Cancellation is permanent. Artifact records linked to this session are retained and remain accessible — they are not deleted. The linked signal set is also unaffected.

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the review session to cancel.
</ParamField>

### Example request

```bash
curl -X DELETE https://api.coherencesystems.net/v1/reviews/rev_01xyz \
  -H "Authorization: Bearer $ATLAS_TOKEN"
```

### Example response

```json
{
  "id": "rev_01xyz",
  "deleted": true,
  "status": "cancelled",
  "deleted_at": "2025-01-16T09:00:00Z",
  "retained_artifacts": ["art_01abc"]
}
```

### Error codes

| Code | Meaning |
|---|---|
| `404` | Review session not found |
| `409` | Session is already cancelled |

## GET /reviews/{id}/summary

Retrieve a consolidated summary of all analysis results for a review session. The summary draws on all artifact records linked to the session and presents findings — persistence behavior, drift events, detected transitions — alongside the original review context and question.

<Tip>
  Use this endpoint to get a single, clean view of what a session found before exporting artifact records or sharing findings with stakeholders.
</Tip>

### Path parameters

<ParamField path="id" type="string" required>
  The unique identifier of the review session.
</ParamField>

### Query parameters

<ParamField query="include_artifacts" type="boolean">
  If `true`, embed the full artifact records in the summary response. Default: `false` (only artifact IDs are included).
</ParamField>

### Example request

```bash
curl "https://api.coherencesystems.net/v1/reviews/rev_01xyz/summary?include_artifacts=false" \
  -H "Authorization: Bearer $ATLAS_TOKEN"
```

### Example response

```json
{
  "review_session_id": "rev_01xyz",
  "name": "post-maintenance-thermal-check-jan14",
  "status": "completed",
  "context": {
    "review_question": "Does the thermal array show persistent structure after the scheduled maintenance window?",
    "time_range": {
      "start": "2025-01-14T00:00:00Z",
      "end": "2025-01-15T00:00:00Z"
    },
    "known_conditions": [
      "Maintenance window 2025-01-14T04:00Z to 2025-01-14T06:00Z",
      "Ambient temperature elevated by 3°C relative to baseline"
    ]
  },
  "consolidated_findings": {
    "persistence_result": "Structure held across fine and mid scales throughout the post-maintenance window. A brief persistence break at mid scale coincided with the maintenance window itself.",
    "total_drift_events": 2,
    "transition_detected": true,
    "transition_window": { "start": 45, "end": 62 },
    "scales_with_data": ["fine", "mid", "broad"],
    "scales_with_gaps": ["broad"]
  },
  "claim_boundaries": [
    "Analysis limited to registered progression 0–100.",
    "Broad-scale structure was not available for the final 20% of the window."
  ],
  "artifact_ids": ["art_01abc"],
  "artifact_count": 1,
  "summary_generated_at": "2025-01-15T18:00:00Z"
}
```

### Error codes

| Code | Meaning |
|---|---|
| `404` | Review session not found |
| `422` | Session has no linked artifact records — create at least one artifact before requesting a summary |
